# Curral Novo

Gestão de ovinos para o pequeno produtor: lotes automáticos, dieta de menor custo por lote, estrutura etária do rebanho, pesagens, FAMACHA, sanidade, manter ou vender e caixa.
Funciona sem internet: os dados ficam no próprio celular (navegador) e podem ser copiados em Base técnica › Ajustes › Cópia de segurança.

Criado por Charles Lobo Pinheiro, Engenheiro Agrônomo.

- Site: publicado pela Vercel a cada envio para `main`.
- Versão nova: altere `VERSAO` em `sw.js` para os celulares baixarem a atualização.
